# 个人月度账本

一个离线优先、低录入负担的工资、支出与储蓄分析网页。每月只需录入工资单汇总信息和发薪后的可用资金余额，应用会自动推算支出、存款变化、储蓄率和公积金数据。

## 功能

- 月度工资单录入与实发金额校验
- 根据相邻月份余额推算支出和存款变化
- 收入、支出、储蓄和余额趋势图
- 图表悬停详情和全屏查看
- 本地 JSON 自动保存
- CSV 导出
- 桌面端与移动端响应式布局

## 运行要求

- Windows 10 或更高版本
- Python 3.9 或更高版本
- 现代浏览器

## 开始使用

克隆仓库：

```powershell
git clone https://github.com/unexpected0/personal-finance-ledger.git
cd personal-finance-ledger
```

启动本地服务：

```powershell
.\start-ledger.ps1
```

然后打开 `http://127.0.0.1:4173/`。

也可以直接双击 `index.html` 查看本机历史数据。本地服务已运行时，页面会自动进入完整编辑模式；服务未运行时仍可查看只读历史，点击新增或编辑按钮会尝试进入本地编辑服务。通过本地服务新增和编辑记录后会自动保存，每次保存也会同步生成仅供本机预览使用的 `data/local-ledger.js`，该文件同样不会被 Git 上传。

首次启动时，程序会自动创建：

```text
data/personal-finance-ledger.json
```

新账本默认为空，不包含作者或其他用户的财务数据。数据只保存在本机项目的 `data` 文件夹中；该文件夹已被 Git 忽略，不会随正常提交上传到远程仓库。标准空账本格式可参考 `examples/personal-finance-ledger.example.json`。

## 计算口径

```text
计算实发工资 = 税前收入 - 个人社保 - 个人公积金 - 税 - 其他扣款
公积金总额 = 个人公积金 + 公司公积金
存款变化 = 本次发薪后余额 - 上次发薪后余额
推算支出 = 上次发薪后余额 + 本月实发工资 + 特殊资金调整 - 本次发薪后余额
储蓄率 = 存款变化 / 本月实发工资
```

工资按所属月份归档，默认在次月 7 日发放。没有期初余额时，第一条记录只作为余额基准，从第二个月开始推算周期支出。
